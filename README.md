# 🧩 MathQuest — חדרי הבריחה

משחק חשבון ולוגיקה לכיתה ז׳ ומעלה עם מנגנוני גיימיפיקציה מלאים.

## הרצה מקומית

```bash
# התקנת תלויות (רק פעם ראשונה)
npm install

# הרצת שרת פיתוח
npm run dev
```

פתח את הדפדפן בכתובת: **http://localhost:5173**

## בנייה לפרודקשן

```bash
npm run build
npm run preview
```

## טכנולוגיות
- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion (אנימציות)
- Web Speech API (זיהוי קול)
- WebRTC (מצלמה)
- localStorage (שמירת התקדמות)
